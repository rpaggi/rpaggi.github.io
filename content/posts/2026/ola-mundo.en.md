This is the first post of the new blog. Each post is a Markdown file inside `content/posts/`, and GitHub Actions publishes everything to GitHub Pages on every push.

## Writing a post

Create a file under `content/posts/YYYY/` with front matter at the top:

```yaml
---
title: "Post title"
date: 2026-10-05T10:00:00-03:00
tags: [tag-one, tag-two]
---
```

## Translations

The Portuguese original lives in `ola-mundo.md`, and this English version in `ola-mundo.en.md`, right next to it. The **PT | EN** switch at the top links both automatically.
